# Exibição de dados e progresso

## Elementos identificados

- Indicadores e estatísticas.
- Resumo semanal.
- Barras de dados.
- Barra de progresso.
- Histórico de check-ins.
- Grade de equilíbrio.

## Regras

- Dê contexto ao número: rótulo, período e unidade quando necessários.
- Barras devem ter rótulo textual ou valor associado.
- Não dependa apenas de cor para diferenciar séries ou estados.
- Progresso deve comunicar valor atual e objetivo quando conhecido.
- Estados vazios devem explicar o que aparecerá quando houver dados.
- Dados ilustrativos no preview são exemplos, não dados reais de usuários.
