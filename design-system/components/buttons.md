# Botões e ações

## Variantes

- **Primary:** ação de maior prioridade da seção; usa o acento roxo.
- **Ghost/secondary:** ação complementar; menor peso visual, sem competir com a principal.
- **Icon button:** ação compacta com nome acessível obrigatório.

## Anatomia

Rótulo claro, área clicável confortável, estados visuais e foco visível. O texto deve começar com verbo quando representar uma ação.

## Estados

| Estado | Orientação |
|---|---|
| Padrão | Contraste suficiente e hierarquia clara |
| Hover | Mudança sutil de brilho/superfície |
| Focus-visible | Contorno perceptível, sem depender do hover |
| Pressed | Feedback breve de ativação |
| Disabled | Aparência inativa e operação bloqueada |
| Loading | Indicar progresso e impedir envio duplicado |

Não use somente mudança de cor para indicar foco, erro ou indisponibilidade. Botões de ícone precisam de nome acessível.
