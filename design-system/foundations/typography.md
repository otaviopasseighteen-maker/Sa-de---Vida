# Tipografia

## Famílias

- **DM Sans:** corpo, descrições, rótulos, navegação e controles.
- **Space Grotesk:** títulos, marca e números que pedem ênfase.

O carregamento das fontes permanece responsabilidade da aplicação que consumir os tokens. Use fontes de fallback sans-serif caso a fonte web não esteja disponível.

## Escala de referência

| Token | Valor | Uso sugerido |
|---|---:|---|
| `--sv-font-size-xs` | 12px | Metadados |
| `--sv-font-size-sm` | 14px | Rótulos e apoio |
| `--sv-font-size-md` | 16px | Texto base |
| `--sv-font-size-lg` | 18px | Texto enfatizado |
| `--sv-font-size-xl` | 24px | Títulos de cards |
| `--sv-font-size-2xl` | 32px | Títulos de seção |
| `--sv-font-size-display` | responsivo | Hero e título de abertura |

## Recomendações

- Mantenha o corpo em tamanho confortável para leitura.
- Use pesos fortes para hierarquia, não para decorar todos os elementos.
- Limite a largura de parágrafos longos.
- Evite títulos excessivamente longos em cards pequenos.
