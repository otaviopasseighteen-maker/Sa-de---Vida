# Espaçamento, formas e efeitos

## Escala de espaçamento

A escala usa uma base de 4px: 4, 8, 12, 16, 20, 24, 32, 40, 48 e 64px. Use valores menores dentro de controles e valores maiores entre seções.

## Formas

| Token | Valor | Aplicação |
|---|---:|---|
| `--sv-radius-sm` | 10px | Campos e pequenos controles |
| `--sv-radius-md` | 16px | Botões e cards compactos |
| `--sv-radius-lg` | 22px | Cards principais |
| `--sv-radius-xl` | 28px | Painéis de destaque |
| `--sv-radius-pill` | 999px | Chips e controles arredondados |

## Elevação e efeitos

- Use bordas translúcidas para separar cards do fundo.
- A sombra de painel deve sugerir profundidade sem criar contorno pesado.
- O brilho roxo é um detalhe de ênfase, não um efeito padrão em todos os elementos.
- Gradientes podem destacar áreas hero, mas o texto precisa permanecer legível.

## Movimento

Transições devem ser curtas e discretas. Respeite `prefers-reduced-motion`; movimento nunca deve ser necessário para compreender informação ou concluir uma ação.
