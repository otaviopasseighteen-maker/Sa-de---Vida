# Cores

## Paleta de referência

| Token | Valor | Uso |
|---|---|---|
| `--sv-color-bg` | `#07090d` | Fundo principal |
| `--sv-color-bg-soft` | `#0d1118` | Fundo alternativo e áreas de apoio |
| `--sv-color-panel` | `#111722` | Cards e painéis |
| `--sv-color-panel-light` | `#151c28` | Superfícies elevadas ou internas |
| `--sv-color-text` | `#f4f7fb` | Texto principal |
| `--sv-color-muted` | `#9da8b8` | Texto secundário |
| `--sv-color-white` | `#ffffff` | Texto sobre fundos de acento quando necessário |
| `--sv-color-accent` | `#7c6cff` | Ação primária e destaque |
| `--sv-color-accent-2` | `#42d9c8` | Acento complementar |
| `--sv-color-line` | `rgba(255,255,255,.09)` | Bordas discretas |

## Regras

- Priorize contraste entre texto e superfície.
- Use roxo para a ação principal e estados de ênfase.
- Use verde-água para apoio, indicadores e detalhes complementares.
- Não use os dois acentos com a mesma intensidade no mesmo bloco.
- Cor não deve ser o único indicador de erro, sucesso ou seleção.

Os valores representam a identidade observada nos estilos atuais; não são uma auditoria formal de contraste de cada combinação.
